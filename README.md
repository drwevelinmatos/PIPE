# PueriFamília 2.0 — UI Candidate v1

Artefato pré-validação para testes formativos com pais/cuidadores.

## Escopo
- Protótipo estático responsivo (mobile-first).
- 6 pathways de demonstração: Febre, Respiração/Bronquiolite, GI/Desidratação, TCE, Convulsão/Crise, Reação Alérgica Grave.
- Uma pergunta por tela.
- Interrupção do fluxo em cenários de emergência.
- Estados semânticos de saída separados: ESCALATE, ASSESSMENT_REQUIRED, ASSESSMENT_RECOMMENDED, HOME_MANAGEMENT_ANCHORED, INDETERMINATE.
- Sem linguagem de “está tudo bem” fora de plano profissional validado.

## Importante
Este pacote é UI Candidate / Human Factors, não substitui o PRR-MR Core 1.0.0 nem a Integration Layer congelada.
A lógica clínica do protótipo é simulada para navegação e estudo de UX. Não usar para atendimento real.

## Executar
Abra `index.html` em navegador moderno.
