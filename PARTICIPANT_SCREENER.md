# Triagem de participantes — estudo formativo

## Objetivo
Selecionar pais/cuidadores representativos do público pretendido sem induzir respostas clínicas.

## Perguntas sugeridas
1. Você é responsável ou cuidador frequente de pelo menos uma criança?
2. Faixa etária da(s) criança(s): <1 ano / 1–4 / 5–9 / 10–15 / outra.
3. Você já usou aplicativo/site para buscar orientação de saúde infantil?
4. Com que frequência usa smartphone? baixa / média / alta.
5. Você se sente confortável lendo textos de saúde no celular? sim / parcialmente / não.
6. Formação profissional em saúde? sim / não. (usar para segmentação, não exclusão automática.)
7. Necessidade de recurso de acessibilidade para usar smartphone? campo aberto.

## Diversidade desejada
Buscar variação de idade do cuidador, escolaridade, familiaridade digital e experiência com crianças de diferentes idades.

## Não usar
Não recrutar com base em doença ativa da criança nem pedir que tragam uma situação médica real para teste.
