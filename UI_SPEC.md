# UI Candidate v1 — Especificação

## Design system provisório
- Primária `#285A81`
- Azul claro `#B9E0E5`
- Branco `#FFFFFF`
- Background `#F7FAFC`
- Texto `#0F172A`
- Títulos: Comfortaa quando disponível
- Corpo: Inter / system sans-serif

## Invariantes de UX
1. Ausência de red flag nunca gera “está tudo bem”.
2. ESCALATE encerra o questionário imediatamente.
3. HOME_MANAGEMENT_ANCHORED só existe com plano profissional válido.
4. INDETERMINATE nunca é convertido em baixo risco.
5. Campos profissionais não aparecem na superfície parental.
6. Uma pergunta principal por tela.
7. CTA de emergência tem prioridade visual.
8. Copy é versionada.
9. Estado semântico e texto de UI são camadas distintas.
10. Este protótipo não executa o motor clínico real.
